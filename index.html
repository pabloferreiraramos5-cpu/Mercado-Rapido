⚙️ Como configurar e editar preços (administrador)

WhatsApp: abra este arquivo em um editor de texto e altere WHATSAPP_NUMBER para seu número com DDI 55 e DDD, somente dígitos (ex.: 5511999999999). Depois publique novamente o arquivo index.html no GitHub Pages.

Produtos e preços: altere a lista DEFAULT_PRODUCTS no código, ou cole abaixo uma lista JSON e clique em “Salvar produtos neste navegador”. Atenção: alterações feitas pelo formulário abaixo são locais neste dispositivo e não atualizam a loja pública dos clientes. Para publicar novos preços, edite DEFAULT_PRODUCTS no arquivo e faça novo envio ao GitHub. Não há painel administrativo remoto nem sincronização automática.

Formato: cada item tem id, name, category, price (número com ponto decimal) e emoji. Para facilitar a atualização pública, mantenha os mesmos IDs e substitua os valores no código.
